Aide NYXA

Les réponses essentielles

Une aide simple pour choisir un outil, comprendre vos données et utiliser NYXA sur tous vos écrans.

Comment utiliser NYXA ?

Choisissez un outil depuis le portail, suivez les étapes indiquées, puis utilisez « Retour au portail NYXA » pour revenir ici.

Mes données sont-elles envoyées quelque part ?

Pour les outils qui fonctionnent localement, vos informations restent dans le navigateur de votre appareil, sauf indication contraire affichée par l’outil.

Un outil ne fonctionne pas. Que faire ?

Actualisez la page, vérifiez que votre navigateur est à jour, puis réessayez. Si le problème persiste, essayez un autre navigateur ou appareil.

Puis-je utiliser NYXA sur téléphone ?

Oui. Les outils sont conçus pour rester faciles à utiliser sur téléphone, tablette et ordinateur.

Pourquoi sauvegarder ou exporter mes données ?

Les données locales peuvent disparaître si le stockage du navigateur est vidé, si vous changez d’appareil ou si vous réinitialisez le navigateur. Une sauvegarde vous permet de les conserver.
