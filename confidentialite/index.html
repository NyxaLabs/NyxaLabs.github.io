Confidentialité

Ce que NYXA traite, ce qui reste sur votre appareil et ce qui dépend de services tiers.

Dernière mise à jour : 22 août 2026

Nature du projet

NYXA Labs est un projet personnel, gratuit, non professionnel et indépendant. NYXA n’exploite pas les informations des visiteurs à des fins publicitaires, commerciales ou de profilage.

Hébergement

Les sites NYXA sont hébergés via GitHub Pages. Lors de la visite d’un site GitHub Pages, GitHub enregistre notamment l’adresse IP du visiteur à des fins de sécurité. Ce traitement relève de GitHub et de sa propre politique de confidentialité.

En savoir plus sur GitHub Pages · Politique de confidentialité GitHub · Documentation GitHub

Stockage local

Certaines fonctions enregistrent des informations uniquement dans le navigateur de votre appareil afin de fournir la fonction demandée. Elles peuvent disparaître si vous effacez les données du navigateur ou changez d’appareil.

  • Portail : préférence de thème, clé nyxa-portal-theme et cache technique du service worker.
  • NYXA Protect : préférence de thème, clé exposition-theme.
  • NYXA Before : situation choisie et cases cochées, clés nyxaBeforeScenario et nyxaBeforeChecks.
  • NYXA Proof : dossier et événements, clé nyxaProofDataV1, avec import/export JSON local.
  • NYXA HomeBook : équipements, clé nyxaHomeBookV1, avec import/export JSON local.
  • NYXA LinkCheck, Reflex et SOS : pas de stockage local permanent détecté ; SOS génère le PDF localement.

Services tiers

NYXA donne accès, selon les outils, à VirusTotal, Have I Been Pwned, Hudson Rock, LeakCheck, DeHashed, Intelligence X, Epieos, Google Translate, Cybermalveillance.gouv.fr, la CNIL, Service-Public, HistoVec, DossierFacile, SignalConso, les Conseils aux voyageurs, Phishing Initiative, PhishTank, Microsoft et aux services de partage.

Le simple affichage d’un lien n’envoie pas volontairement vos données à ce service. Lorsque vous choisissez d’ouvrir ou d’utiliser un service tiers, sa propre politique de confidentialité et ses propres conditions s’appliquent. Les liens de NYXA Protect qui passent par Google Translate utilisent ce service avant l’accès au site concerné.

Dans NYXA LinkCheck, l’URL collée reste dans la page NYXA jusqu’à l’action de l’utilisateur. Lorsque vous cliquez pour vérifier dans VirusTotal, l’URL est transmise à VirusTotal. Ne soumettez jamais une URL privée contenant un jeton secret, un lien de réinitialisation ou une information confidentielle.

Partage

Les boutons de partage utilisent des liens ou la fonction de partage du navigateur et du téléphone. Ils n’envoient des informations vers la plateforme choisie qu’à la suite d’une action de votre part. NYXA n’intègre pas de SDK de réseaux sociaux.

Cookies et traceurs

NYXA n’ajoute pas de traceur publicitaire ou de profilage. Certaines fonctions utilisent le stockage local du navigateur pour fournir la fonction demandée. L’hébergeur GitHub peut appliquer ses propres mécanismes techniques conformément à sa politique.

Données sensibles

N’enregistrez pas dans les outils NYXA de mot de passe, code secret, numéro complet de carte bancaire ou autre secret qui n’est pas nécessaire à la fonction utilisée.
